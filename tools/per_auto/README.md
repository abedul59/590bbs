# PER Auto Windows

台股六大指標與本益比區間資料抓取工具。資料會同步到：

- 590bbs「總大六大指標和本益比區間分析」
- 原 Stock Dashboard（相容保留）

儀表板：<https://590bbs.vercel.app/macrowave?view=stock-dashboard>

## 使用方式

1. 下載 `PER_Auto.exe`。
2. 將 `stock_id_settings.example.csv` 複製並改名為 `stock_id_settings.csv`，與 EXE 放在同一個資料夾。
3. 在 CSV 中一行填一個股票代碼（可保留第一行 `stock_id`）。
4. 雙擊 EXE，輸入 1 到 12 的分析月份。
5. 程式會在同一資料夾留下 JSON，並將結果同步到兩個網站。

## 本益比區間年度

目標價使用「估值年度 EPS × 歷史本益比」計算。每年 1–8 月估算當年度；進入 9 月後改估下一年度：先用已公布月份補齊當年度營收，再依營收成長率推估下一年度營收，最後以平均淨利率與股本換算下一年度 EPS。例：2026 年 10 月執行時，輸出的是 2027 年 EPS 與目標價區間。

營收成長率採「最新月年增率」與「近六個月平均年增率」兩者較低值，避免單月跳升讓預估過度樂觀。歷史表會另外保留執行當年度（例如 2026 年）的截至目前最高、最低價、全年估計 EPS 與本益比，不會再直接從 2025 年開始。

## 六大指標評分

每項依 `AA=4、A=3、BB=2、B=1、C=0` 評分，再以實際可評項目計算 0～4 分平均：

- 營收：最近六個月營收年增率與成長動能。
- 營業利益率：近四季平均、穩定度與單季衰退幅度。
- 稅後淨利：最近八季換算的四季年增率與成長動能。
- EPS：近四季 EPS 合計。
- 存貨：近四季存貨週轉率與連續下降幅度；確實不適用的產業才不評分。
- 現金流：營業活動現金流加投資活動現金流所得的自由現金流，檢查近四季與近六季累計。

每項輸出都含判定理由。舊版 JSON 若缺少投資活動現金流，網站只會以營運現金流暫評並提示重新執行新版 EXE。

網站的模擬試算、歷史股價、營收、淨利、六大指標與 Q4 檢查分頁，都會列出公式、本次代入值、計算結果及爬蟲原始資料連結。新版 JSON 也會保存 `Sources`、`Formulas`，六大指標各項另含 `SourceURL` 與 `Formula`，方便獨立追查。

若任一網站暫時無法連線，程式會自動重試三次，並繼續同步另一個網站。大量股票之間會隨機等待 40 到 120 秒，以降低來源網站封鎖風險。
